# Our online courses — каталог курсов

Pixel-perfect вёрстка и «оживление» блока-каталога по макету Figma: живой поиск по названию и
фильтрация по категориям. Чистый стек без библиотек и фреймворков.

- **Демо (Vercel):** _ссылка будет добавлена после деплоя_
- **Репозиторий:** https://github.com/laviercasey/course-catalog
- **Макет:** [Figma — Test Task](https://www.figma.com/design/iuXLXifXgv4ZCzad0KeYKr/Test-Task)

## Стек
- **HTML5** — семантическая разметка.
- **SCSS** — методология **БЭМ** (https://ru.bem.info/methodology/), один блок = один файл, `@use`, дизайн-токены через CSS-переменные.
- **Vanilla JavaScript** (ES-модули) — без библиотек и фреймворков.
- **Dart Sass** — единственная dev-зависимость (компиляция SCSS → CSS).

## Возможности
- **Живой поиск** по названию курса — мгновенно, без перезагрузки (с debounce ~150 мс).
- **Фильтрация по категориям** (All / Marketing / Management / HR & Recruting / Design / Development) с актуальными счётчиками.
- Поиск и категория работают **вместе** (логическое И).
- **Пагинация «Load more»** — первая страница 9 карточек (как в макете), по клику догружаются остальные; кнопка прячется, когда показывать больше нечего.
- **Плавная анимация** появления карточек при фильтре/поиске/догрузке (с уважением к `prefers-reduced-motion`).
- **Доступность**: `aria-live`-объявление результатов, навигация по табам стрелками (roving tabindex, Home/End), видимый `:focus-visible`.
- Без мерцания: карточки рендерятся один раз, фильтр лишь переключает видимость (фото не перезагружаются).
- Пустое состояние, когда ничего не найдено.
- **Резиновый адаптив** от 1920 до 320 px **без единого media-брейкпоинта**.

## Запуск локально
```bash
npm install          # поставит sass
npm run build        # соберёт css/main.css из scss/
# открыть статикой (нужен http, т.к. используются ES-модули):
npx serve .          # затем открыть http://localhost:3000
```
Для разработки со слежением за изменениями: `npm run watch`.

> `css/main.css` закоммичен намеренно: проект разворачивается как **чистая статика без шага сборки**
> на хостинге, поэтому собранный стиль — это деплой-ассет. Источник правды — `scss/`, пересборка — `npm run build`.

## Структура
```
index.html               # разметка (БЭМ-классы, Lato c Google Fonts)
scss/                    # слоистая архитектура; main.scss = @use слоёв, index = @forward партиалов
  main.scss              # точка входа: abstracts → base → utilities → blocks
  abstracts/             # _tokens (дизайн-токены: цвета, типографика, тени, радиусы)
  base/                  # _reset (сброс) + _base (html/body)
  utilities/             # _visually-hidden
  blocks/                # по одному файлу на БЭМ-блок
    _catalog, _hero, _toolbar, _tabs, _search, _grid, _card, _load-more, _decor
css/main.css             # скомпилированный стиль (деплой-ассет)
js/
  data.js                # курсы (9 из макета + 8 демо) + категории с вычисляемыми счётчиками
  render.js              # чистые функции рендера (карточки, табы)
  catalog.js             # логика: фильтр + поиск (debounce), пагинация, видимость, a11y (roving tabindex, aria-live)
  app.js                 # инициализация
assets/                  # изображения курсов, иконки и декор (экспорт из Figma)
```

## Решения по реализации
- **Pixel-perfect.** Все значения (цвета, кегли Lato 400/700/900, сетка 12 колонок, контейнер
  1230 px с полями 345 px, карточки 390×438, фото 390×240, gap 30, тени, цвета бейджей по
  категориям) сняты напрямую из node-дерева Figma. Изображения, иконки и декоративные фигуры —
  оригинальные ассеты, экспортированные из макета.
- **Резиновый адаптив без брейкпоинтов.** Контейнер — центрированный `min(1230px, 100% - 2rem)`
  (на 1920 даёт ровно 345 px поля, на мобайле — 16 px). Сетка — `repeat(auto-fit, minmax(...))`,
  плавно перестраивается 3 → 2 → 1 колонка. Hero и отступы — через `clamp()`. Тулбар — `flex-wrap`.
  Ни одного `@media`.
- **Чистый JS.** ES-модули, иммутабельность: рендер из данных через `map`/шаблоны, фильтрация —
  чистые функции, исходный массив курсов не мутируется.
- **БЭМ.** Строгое именование, активный таб реализован без вложенных селекторов элементов в
  модификатор (через CSS-переменную `--tabs-fg`).

## Важно про данные
В макете нарисовано 9 карточек, а счётчики в табах рассчитаны на полный каталог
(All 17, Marketing 4, Management 3, HR & Recruiting 5, Design 2, Development 3).

Реализация:
- **первая страница — 9 карточек из макета** (в том же порядке), затем «Load more» догружает остальные;
- к 9 курсам из макета добавлены **8 демо-заглушек** (`id 10–17`), которые **переиспользуют те же фото** —
  чтобы пагинация «Load more» была рабочей, а счётчики совпадали с макетом. Распределение заглушек по
  категориям подобрано под макет;
- **счётчики табов — вычисляемые** из данных (не захардкожены) и в сумме дают значения макета:
  All 17, Marketing 4, Management 3, HR & Recruiting 5, Design 2, Development 3;
- опечатки макета **исправлены**: «Product Management Fundamentals», «HR Management and Analytics»
  (один пробел), категория «HR & Recruiting».
